# 火候

陶艺窑炉烧成曲线编辑器。支持拖拽关键点调整目标温度与到达时间，自动识别升温、保温和降温阶段，按泥料与釉料规则检查升温速率、保温时长和降温速度，并导入记录仪 CSV 进行偏差比较。

```bash
corepack pnpm install
corepack pnpm dev
corepack pnpm build
# 合并规则与 store 端到端验证（纯 node，无需浏览器）
node scripts/verify-merge.mjs
node scripts/verify-store.mjs
```

所有窑次、模板和记录仪数据均保存在浏览器本地。

## 离线协作与修订合并

窑边平板与办公室电脑可同时离线工作同一个窑次，网络恢复后通过「同步中心」交换修订包（JSON）：

- **逐项修订号**：曲线关键点、实测采样、时间偏移各自带 `rev`，窑次还有整体 `curveRev`；每次修改修订号递增。
- **按修订号三向合并**：以最近一次合并的内容（`syncShadow`）为公共基线，只有一边动过的直接采纳；两边都改过同一个关键点时自动保留**峰值温度更高**的一版，另一版进入「待确认」由人工裁决（采样 / 偏移在双方都改时取修订号更高者；一端改一端删时保留修改版、删除操作待确认）。
- **结论联动失效**：关键点增删改后阶段立即重划，绑定在旧阶段上的偏差与开裂风险结论标记失效并按新曲线重算（合并、裁决后立即重算；编辑页拖拽后防抖重算）。
- **旧窑次迁移**：没有修订号的历史数据在打开时先按现有内容补齐 `rev=1` 与基线，再参与合并。
- **失败留草稿**：修订包 / CSV 解析或合并失败时原始载荷留存为本地草稿（不覆盖现有数据），可一键重试；合并在深拷贝上进行，中途任何窑次出错都整体放弃。
